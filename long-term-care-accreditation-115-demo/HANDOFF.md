# 長照機構評鑑 115｜示範案例交接

## 目前狀態

- 已建立一個可直接開啟的 HTML 簡報式講義示範。
- 內容是主題示範版，尚未接入正式「長照機構評鑑 115」原始檔。
- 互動功能包含目錄切頁、鍵盤左右鍵、Prompt 複製、講師筆記暫存、筆記匯出、全螢幕播放。

## 主要檔案

- `index.html`：講義主頁
- `styles.css`：版面與視覺樣式
- `app.js`：投影片資料與互動邏輯
- `source/course-outline.md`：課程大綱與素材需求
- `downloads/prompts.md`：逐頁圖片生成 Prompt

## 下一步

1. 放入正式評鑑資料或教材原稿。
2. 將 `app.js` 裡的 `slides` 陣列替換成正式課程頁面。
3. 若要使用完整圖片講義，先用 `downloads/prompts.md` 產生每頁圖，再把 `visualMarkup()` 改成載入圖片。
4. 預覽桌機與手機寬度，確認文字不溢出、操作按鈕可點、筆記可匯出。
