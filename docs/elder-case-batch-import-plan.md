# 永和區獨老個案清冊分批匯入規劃

## 目標

讓承辦管理者可以把新北市/永和區獨老個案清冊分批匯入系統，先完成欄位檢查、查重、批次確認，再正式寫入個案名冊，避免一次匯入大量資料後難以追蹤或回復。

## 本次 Excel 判讀

檔案實際仍是 Office 加密容器，即使檔名標示無密碼，系統讀取時仍需先處理解密或要求使用者另存為真正的標準 `.xlsx`。目前分析結果如下：

| 工作表 | 筆數 | 建議處理 |
| --- | ---: | --- |
| `(勿動)疑似獨老個案名冊` | 15,041 | 候選大表，僅作資料來源，不建議直接全量寫入正式名冊。 |
| `75歲以上` | 7,157 | 候選分齡表，可作分批篩選來源。 |
| `65到74歲` | 7,884 | 候選分齡表，可作分批篩選來源。 |
| `僅本市列冊獨老` | 246 | 優先匯入正式名冊。 |
| `統計結果(勿動)` | 統計資料 | 不匯入個案。 |
| `附錄` | 訪視結果代碼 | 作為訪視結果代碼參考。 |

## 匯入批次狀態

建議新增匯入子系統時，每次上傳都建立一個批次：

1. `uploaded`：已上傳，尚未解析。
2. `parsed`：已讀取工作表與欄位。
3. `mapped`：已完成欄位對應。
4. `validated`：已完成必填、格式與查重檢查。
5. `ready_to_commit`：承辦確認可寫入。
6. `committed`：已正式寫入 `elder_cases`。
7. `reverted`：批次已撤回或停用。
8. `failed`：解析或寫入失敗。

## 分批匯入畫面流程

### 1. 上傳與選擇工作表

- 上傳 `.xlsx`、`.csv` 或 `.txt`。
- 若偵測仍是加密 Office 檔，要求輸入密碼或提示另存為標準 `.xlsx`。
- 顯示工作表清單與筆數。
- 預設建議選擇 `僅本市列冊獨老`。

### 2. 欄位對應

系統自動對應欄位，承辦可調整：

| Excel 欄位 | 目標欄位 |
| --- | --- |
| 編碼 | `case_code`，空白時自動產生 |
| 服務單位 | `service_unit` |
| 姓名 | `name` |
| 性別 | `gender` |
| 出生日期 | `birth_date` |
| 年齡 | 只作檢核，不直接作主資料 |
| 身分證號 | `id_number` |
| 聯絡電話 | `phone` |
| 手機 | `mobile_phone` |
| Line ID | `line_id_status` |
| Line ID 內容 | `line_id_note` |
| 緊急聯絡人姓名 | `emergency_contact_name` |
| 緊急聯絡人關係 | `emergency_contact_relationship` |
| 緊急聯絡人電話 | `emergency_contact_phone` |
| 戶籍縣市/區/里/地址 | `household_*` |
| 居住城市/區/里/詳細地址 | `residence_*` |
| 居住說明 | `residence_address_note` |
| 獨居資格 | `solitary_status` |
| 訪視結果 | `import_visit_result`，正式訪視紀錄另建 |
| 訪員姓名 | `import_visitor_name`，正式派案另建 |

### 3. 資料清理與轉換

- 民國日期轉西元日期。
- `0`、空白、`未填` 類值統一視為空值。
- 電話欄位保留原始字串，避免分機與備註被誤刪。
- 地址優先使用居住詳細地址；若空白，使用居住地址；再空白才使用戶籍地址。
- 行政區優先使用居住區；若空白，使用戶籍區。
- 里別優先使用居住里；若空白，使用戶籍里；仍空白則標記為待補里別。

### 4. 檢核

必填建議：

- 姓名
- 身分證號
- 出生日期或年齡至少一個
- 地址
- 行政區

查重規則：

- 同一工作空間內 `id_number` 相同，預設視為同一個案。
- 若 `id_number` 缺漏，改用姓名 + 出生日期 + 地址進行疑似重複提示。
- 若 `case_code` 空白，匯入時自動產生，例如 `YH-115-000001`。

### 5. 分批確認

每批先顯示：

- 總筆數
- 可匯入
- 需補資料
- 疑似重複
- 地址/里別缺漏
- 日期格式異常

承辦可選：

- 只匯入可匯入資料
- 匯入並標記缺漏待補
- 下載錯誤報表
- 取消整批

### 6. 正式寫入與回復

正式寫入時每筆個案都保存：

- `import_batch_code`
- `source_sheet_name`
- `source_row_number`
- `raw_import_data`

這樣後續可以：

- 查某筆資料從哪個 Excel、哪個工作表、哪一列來。
- 回復整批匯入。
- 匯出原始對照表給承辦檢查。
